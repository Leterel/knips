# Store-Vorbereitung

Eigenständige deutsche Store-Texte, Icon512×512 und Titelgrafik1024×500.
Die SVG-Dateien basieren auf den vorhandenen eigenen App-Icons; PNGs im lokalen
Chrome gerendert. Titel-/Kurz-/Langtextgrenzen geprüft, Grafiken visuell geprüft.
Die Texte beschreiben jeweils den Offline-/werbefreien Build, nicht adsTest.

Datenschutztexte sind gekennzeichnete Arbeitsentwürfe. Fehlende Betreiber-/Kontakt-
und Hostingangaben müssen vor einer öffentlichen Privacy-Seite ergänzt werden.
Keine Store- oder Anzeigenzulassung ist durch diese Unterlagen bestätigt.

Quelle der Assetanforderungen:
